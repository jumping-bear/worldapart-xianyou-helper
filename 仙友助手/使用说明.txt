不问凡尘 · 仙友助手 v1.8.0
========================================

三步搞定
--------
1. 双击「一键安装.bat」（自动找到游戏目录并装好运行环境 + 插件）
   - 安装前请先完全退出游戏
   - 如果没自动找到，按提示把 A1 文件夹拖进窗口回车
2. 启动游戏，停在主菜单约 20 秒，让插件自动导出存档副本（不用退出游戏）
   - 第一次启动要生成适配文件，可能慢 1~3 分钟、窗口像卡住，属正常，别关游戏
3. 双击「仙友助手.exe」，会打开一个网页显示进度

就这三步，不用手动解压 BepInEx、不用拖 dll。
安装器会写入本机数据目录和游戏目录；升级安装时会保留已有的模块开关。

功能开关
--------
仙居楼互动、NPC 天赋、NPC 物品、炼丹、炼器、奇遇、支线和留影石默认都开启。双击「功能设置.bat」可分别开关：
- 已完成「十八摸」成就，可关闭仙居楼互动，只解析天赋、物品、炼丹、炼器、奇遇、支线和留影石。
- 只关心仙居楼互动时，可关闭另外七个模块。
- 全部关闭时，不再解码存档，只显示设置提示。
设置会保存到 config.json。若查询工具正在运行，设置变化后会自动应用；也可重新打开。

NPC 天赋与组合筛选
----------------
「NPC天赋」页签按天赋分组，优先突出匹配的天赋名称和完整效果描述；拥有者 NPC
嵌套在天赋卡片下方。NPC 详情始终默认收缩，点击 NPC 行才会展开其全部天赋；
当前匹配天赋会再次高亮，便于比较其他天赋是否值得占用同道位置。

天赋和 NPC 使用两个独立搜索框：
- 「找天赋」搜索名称、效果、悬停和触发描述。
- 「找 NPC」搜索 NPC 名称；两个搜索条件同时填写时取交集。

默认只显示两个搜索框、区域和具体位置，避免筛选区拥挤。位置显示完整层级，
先选区域后，具体位置选项会自动联动。「更多筛选」中可按需展开：
- 天赋分类、品质、境界
- 已解锁 / 未解锁
- 已同道 / 未同道
「清空筛选」可一次恢复全部条件。

分类依据游戏资源中的分类图标标识显示为「战斗、技艺、游历、财富、交情、性格」，
括号内保留原始 category ID 供核对。以后新增但未识别的分类仍自动显示「分类 N」。
页签和筛选条件会保存在浏览器 localStorage，刷新后继续保留。

NPC 物品与偷窃查询
----------------
「NPC物品」页签以物品为主列表，用于反查「想要的东西在谁身上、能不能偷」。
物品条目默认全部收起，标题行直接给出可偷处数、最高成功率和总数，方便一眼判断值不值得点开。
展开后可按成功率、持有数量或名称排序，默认成功率优先；每位持有者下方直接列出
一次最多能偷几个、善恶值与好感的变化，失手会触发击杀的会单独标红。
单个物品先显示 30 位持有者，底部「显示更多」可继续加载，不做嵌套滚动条。
点击 NPC 行可展开其全部持有物品，当前物品会高亮并标注「当前物品」。
展开内容分成「偷取」和「索要」两段，两套数据互不相同：
- 偷取：只看他背包里实际持有、且有偷窃参数的物品。
- 索要：来自该 NPC 的索要模板（3~8 件固定物品），不一定在他背包里；
  标注「不在背包」的是模板里有、身上没有的，标「不可索要」的是物品本身不允许索要。
  每件物品显示好感消耗（游戏原始的 intimacy_deduction 值），无好感门槛、每周期 1 次；
  好感消耗不随对方境界折算，页面不做二次计算。
NPC 卡片标题会同时给出「可偷 N 件」和「可索要 N 件」。

能否偷取由两层共同决定，页面会分别标注：
- 「NPC 不可偷」：该角色本身受保护，身上物品一律无法下手。
- 「物品不可偷」：物品没有偷窃参数，谁拿着都偷不了。
可偷的持有者会显示成功率、一次最多偷几个，以及失手后果（是否触发击杀、善恶值扣多少、好感扣多少）。
点击 NPC 行可展开其全部持有物品，便于比较同一目标身上还有什么值得顺走。

搜索和筛选：
- 「找物品」按物品名称匹配；「找 NPC」可选，两个条件同时填写时取交集。
- 只填「找 NPC」时，列表会自动切换成「按 NPC 查看」：每位 NPC 一张卡片，
  标题直接给出他身上可偷几件、共几件以及所在地，点开就是他的全部物品。
  清空 NPC 搜索即回到物品列表。
- 区域与具体位置联动；「偷窃」可选只看可偷或只看不可偷；「索要」可选只看可索要（只保留索要模板里允许索要的物品）。
- 「更多筛选」里可按物品类型和品质收窄。

炼丹与丹方盘面
------------
「炼丹」页签顶部是炼丹等级、炉火、丹方手记进度和盘面拾取点统计，下面是游戏里那张固定的
炼丹盘面（由游戏资源中的 ACMP 地图文件解码而来，500×500 格，共 1590 个拾取点）：
- 丹方 56 个、丹方属性 431 个、减毒 85 个、奖励 950 个、传送口 34 对
- 另有 45 条药材轨迹（地面上的可拾取药材路线）
盘面地形按原图着色：棕为山、青为沼泽。

筛选区分四块：
- 显示对象：丹方、丹方属性、减毒、奖励、传送口，每项右侧实时显示当前还剩多少条
- 筛选条件（只作用于丹方与丹方属性）：五行、阶数、药效关键词；丹方与丹方属性都不勾时整组置灰
- 视图：迷雾、药材路线（默认关闭）、隐藏已拾取
- 搜索框：名称与效果文案，命中的字会高亮
每行右侧有「清 / 全」；按住 Alt 点任意一项等于只选它。选中的条件会列在上方，点 × 单独移除。
结果按类型分组并给出条数，组头「只看这类」可一键收窄；底部显示「结果 N 项 · 已拾取 M 项」。
没有结果时会给出「放宽到全部阶数 / 清空药效 / 恢复五行 / 清空搜索」等一键恢复按钮。
筛选状态记在本机浏览器里，下次打开炼丹页还是上次的条件。

「药材路线」默认关闭：打开后会在地图上画出 45 条药材分布轨迹（含各种妖丹），
鼠标停在线路上才会弹出药材名，避免几十条线叠在一起看不清。

丹方详情给出判断强度的依据：五行与品阶、丹毒上限、成丹门槛（凡/仙/神三档）、
灵力与时长、可炼次数，以及填入真实数值后的效果说明（例如「攻击力提升 2%，持续 214 回合」），
并标注该丹方是否已记入你的丹方手记。

传送提示：山不可通行，因此盘面被切成若干互不连通的小块。不在你出发区域的拾取点
会在列表里带「遁」标记；选中后盘面会直接画出传送门的入端和出端（青色虚线 + 「入」「出」圆圈），
列表项和详情都会写明是双向还是单向、需要消耗哪种妖丹几枚（不需要妖丹的门会标「免费」）。
点击筛选结果或盘面上的圆点，地图会打上高亮环并滚动到对应位置。

炼器与器胚盘点
------------
「炼器」页签顶部是炼器等级、经验、真火、天赋点和历史最高器契，下面分五块：
- 我的器胚：列出背包里持有的器胚、数量、五行需求与缺口、洗练材料和推荐灵性。
- 洗练保底：同境界、同品质法宝共享计数，显示距离紫/橙保底还差几次。
- 全部器胚：收录全部 78 件器胚，可按境界、部位（攻击/防御/辅助/速度）和名称筛选；
  展开后显示棋盘布局（虚线＝封炉格，带色格＝聚灵格）、炼制要求、词条槽与洗练材料、四阶门槛。
- 材料盘点：按五行统计材料件数与灵性合计，并按器胚推算库存缺口。
- 我的法宝：列出背包中的法宝，含器契分数、基础属性、词条（含未激活）、洗练材料和保底计数。

器胚棋盘为 5×5 / 6×6 / 7×7，五行需求按「该五行精粹需占几格」计算；
缺口＝背包该五行材料总件数－需求格数，只作库存参考，实际摆盘还受封炉格与聚灵格影响。
器契达到凡/玄/地/天四档门槛即对应阶，天阶最高。

奇遇与结局收集
------------
「奇遇」页签顶部先显示当前读取的角色（姓名、境界、层数、存档文件）。如果工具显示的不是
你想看的角色，双击「功能设置.bat」，在菜单底部选「选择存档角色」，固定到对应角色；
选「自动跟随最近存档」恢复默认。

「我想…」四个入口对应四种常见用法：
- 出发前检查：只看还没达成、且当前属性达不到某些选项门槛的奇遇，避免因属性不够走进坏结局。
- 挑奖励：只看当前境界还没达成的奇遇，方便出发前看奖励和选择路线。
- 奖励图鉴：按物品反查，按参考价值从高到低排列，先看最值得主动去拿的奖励。
- 看收集：只看已达成/历史达成的奇遇，适合收集流补漏。

按奇遇：每个奇遇按境界分组，标题行给出是否已达成、结局进度、是否一次性、地点与定位可信度。
展开后：
- 「选项条件」按选项分组，逐条标出 ✓/✗ 和当前值，例如「体魄 >= 7（当前 8）」「灵石 >= 200（当前 1200）」；
  同一选项的成功/失败分支会分别标出，不再把所有门槛混在一起。
- 每条结局先显示「奖励」，物品按品质上色（白 0 → 绿 1 → 蓝 2 → 紫 3 → 橙 4 → 红 5），并标「品质N」；
  已达成的那条整条高亮。
- 「达成路径」紧跟奖励，用带序号的步骤和 › 箭头展示，例如
  「① 下水帮老婆婆捞包袱 › ② 体魄检定成功」；没有写路径的结局会如实留空。
- 剧情摘要与结算说明放在路径之后，优先级低于奖励和路径。
- 「完整对话分支（可选）」默认折叠，只作补充；分支条件带 ✓/✗。
- 已结算的奇遇额外显示「实际所得」和「选择记录」；括号里的“累计选 N 次”是存档点击次数，不是奖励倍数。

探索属性等级：读取存档里的体魄/灵机/神识/辩道/医术经验，按配置表的等级上限换算成当前等级；
页面底部会显示每个属性的等级与经验进度。历史达成记录按角色保存在本地，突破或旧存档被覆盖后，
仍能在「看收集」里看到曾经拿过的结局（不会写回游戏存档）。

品级说明：上品/中品/下品只表示该结局奖励的平均高低，具体拿什么以每条结局的掉落为准。

境界说明：奇遇绑定所在地点。配置里没有“角色境界高于某值就关闭奇遇”的硬条件；突破后低境界奇遇
仍然存在，但需要回到对应地点才会遇到。当前境界的奇遇建议先清，页面顶部也有同样提示。

按物品反查：以奖励物品为主列表，可按品质、物品类别筛选，只看有用途/未拥有，并可按参考价值/品质/名称排序；
展开物品可看到「物品描述」、用途标签和参考价值理由。用途里的「NPC 求购」表示 NPC 会收购它，
或任务需要它；「炼丹药材 / 炼丹成品 / 炼器材料」表示可作对应配方或产物。
每条来源行有醒目的「查看奇遇」按钮，点击会滚动到对应奇遇并展开，不会把页面拉回顶部。

地点定位分三档：
- 位置确定：奇遇有独立交互点或传送入口，直接读到具体场景和交互物名称。
- 位置推断：没有独立交互点，地点由任务文案里的场景名、触发条件或母事件继承得到。
- 位置未定：配置里确实找不到线索，页面会如实标注，不猜。

奇遇数据全部来自游戏配置与只读存档，不写入、不修改任何存档。

游戏版本更新与配置兼容
------------------
工具启动或数据更新时，会读取游戏当前 YooAsset 清单，按资源哈希和大小判断配置是否变化：
- 配置没变：直接使用匹配缓存，不解压 bundle，也不导入 UnityPy。
- 配置变了：自动提取仙居楼互动、天赋、物品、炼丹、炼器、奇遇、支线和留影石所需的新配置，无需等待工具发布新版。
- 提取失败：依次使用旧兼容缓存、EXE 内置快照，单个模块失败不影响其他模块。

页面会显示当前配置来源：「游戏当前配置 / 兼容缓存 / 内置快照」。
缓存位于 %LOCALAPPDATA%\WorldApartTouchProgress，不会打入安装包。
新增字段、新 ID、新分类、名称或描述变化、资源换哈希都可自动适配。
如果游戏大改存档结构、资源加密或 Unity 格式，工具会提示异常，这种情况仍需更新工具。

日常使用与刷新逻辑
----------------
双击 仙友助手.exe 后会打开网页，同时弹出一个黑色小窗口——**别关它**，
它负责每 3 秒检查一次数据（最小化即可，关掉就等于停止检查）。
网页也每 3 秒检查内容版本，只有数据、模块设置或界面版本变化时才整页刷新；无变化不刷新。

平时不用按 F8：插件在游戏启动约 5 秒后首次扫描，之后每 60 秒自动扫描一次。
只有磁盘存档发生变化时才重新解密；没有变化就跳过。
想马上刷新：先在游戏内保存，再按 F8，插件会强制更新全部存档副本。

注意：自动扫描和 F8 都只能读取已经写入磁盘的存档。
游戏里刚获得但尚未保存的进度，需要先手动保存或等待游戏自动存档。
只看一次就够的话，运行后直接关掉那个黑窗口即可。

安装器默认关闭游戏内的 BepInEx 控制台黑窗，日志仍写在 游戏目录\BepInEx\LogOutput.log。
需要排查插件问题时，把 BepInEx\config\BepInEx.cfg 里 [Logging.Console] 的 Enabled 改成 true，重启游戏即可看到控制台。

各模块的来源存档可能不同
----------------------
仙居楼互动沿用原规则：从所有有效副本中选总进度最高的一份，避免选到进度较低的旧档。
NPC 天赋和 NPC 物品选最新有效存档，并优先采用原始 gameworld.msgpack 的修改时间，
避免按 F8 同时重写全部副本后误判新旧。各页签分别显示来源和原始更新时间。

仙居楼互动怎么读（成就「十八摸」）
----------------------------
进入仙居楼与入住的仙友互动，每位仙友 3 个部位、每个部位 6 段，共 18 段
（0~3 四段升阶、4 循环段、5 回落段）。
彩格绿色 = 已收，红色 = 缺。满 18/18 才算 1 位。
成就「十八摸 Ⅰ/Ⅱ/Ⅲ/Ⅳ」分别要 1/3/5/10 位。
带「未入住」标记的仙友还没入住小重天，显示 0/18 是正常的。

最容易漏的两段
--------------
- 2（第三段）：点太快会被跳过，建议每秒一下。
- 5（回落段）：点完升阶后必须停手，等循环和回落播完（3~5 秒）。
另外只有「入住小重天」的仙友才会记录。

安全与卸载
----------
- 插件和查询工具只读，不修改存档；插件只是调用游戏自带的解密函数导出副本。
- 查询结果、配置缓存和浏览器筛选均只保存在本机。
- 卸载：删掉 游戏目录\BepInEx\plugins\SaveDecryptProbe 文件夹即可。
- 若游戏更新后出现启动异常，把 游戏目录\winhttp.dll 删掉即恢复原版启动方式。
