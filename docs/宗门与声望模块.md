# 宗门与声望模块

> 版本线：1.9（宗门/声望）
> 模块键：`sect`（宗门）、`reputation`（声望）
> 数据快照：`sect_meta.json`、`reputation_meta.json`

## 1. 目标与结论

把「宗门」和「城镇声望」两条独立循环做成两个只读页签，回答三个问题：

1. 我现在在宗门/城镇里处于什么位置，离下一档还差什么；
2. 本期还能拿多少贡献/声望/灵石，做完会不会跨档；
3. 手里的贡献/灵石能换什么，哪些兑换被职位、境界或声望卡住。

两条循环互不兑换：

- **宗门**：做宗门任务/灵材征收 → 贡献 + 宗门声望 → 贡献兑换藏经阁物品；宗门声望只用于职位晋升。
- **声望**：做城镇委托 → 城镇声望 + 灵石 → 城镇声望解锁货架档位；购买货架物品另花灵石。

已核对的关键数字：

- 每个可玩宗门 23 件兑换，单宗全清 **26240 贡献**（8 件灵果灵物 + 15 件功法招式）。
- 8 个开放城镇：临州、砚州、白獠部、归鹤镇、青岚洲、雨塘村、烈砂关、青麦村。
- 货架首档统一 400；临州/砚州另有 600 档特殊物品（玄霞露/玄牝玉液）；其余档位为重复配置。
- 委托每城每次刷新 9 条，单条 100–200 声望 + 150–900 灵石。

## 3. 页面结构

### 宗门（`sect`）

1. 顶部行动卡：待提交 / 进行中 / 晋升缺口 / 可兑换；下方一条统计带显示当前贡献、委托板、累计贡献、宗门声望、灵石。
2. 左栏本期任务：待提交排最前（金色高亮），其次进行中、已提交、委托板可接；每条显示目标、地点、数量与进度。
3. 右栏晋升：只展示当前 → 下一职位的条件与进度，完整职位路径折叠；下方本月收入。
4. 左栏灵材征收：本期委托空态 + 可征收清单。
5. 底部贡献兑换：显示当前可兑换件数与「再攒 X 贡献可换「物品」」；支持全部/灵果灵物/功法招式筛选、搜索、只看可兑换、按价格/职位/名称排序、单品模拟兑换与重置。

### 声望（`reputation`）

1. 顶部行动卡：可接委托 / 可跨档城镇 / 下一档缺口 / 最高城镇；下方统计带显示总声望、开放城镇、已解锁货架、已见解锁。
2. 城镇 chip：可跨档的城镇优先，其次按可获声望与当前声望排序；可显示未开放城镇（默认隐藏）。
3. 选中城镇：顶部显示当前声望、完成后声望、可接与进行中数量。
4. 左栏先放「顺路清单」：按地点合并全部委托，聚合「本次需收集」的材料与总数；下方再列本期委托明细，区分可接取/进行中，显示目标描述、地点、目标物/怪物/NPC、数量与品质。
5. 右栏放声望货架与称号档位：每档门槛、解锁状态、价格、物品清单；重复档位标注「与 X 档相同」；称号档位折叠，当前称号高亮。
6. 底部城镇总表：当前声望、称号、本月委托、完成后、跨档、下一档缺口；本月可跨档的城镇高亮，点击行切换城镇。

## 5. 边界与数据坑

1. **宗门 6–10 是剧情势力**：凌霜宗、曜日阁、九劫雷狱、骸谷、世乐合欢有职位与任务，但没有藏经阁兑换 NPC；模块标记为不可加入，不再输出「未配置藏经阁」告警，只在可加入列表里说明。
2. **本期任务不是只有 3 个**：`current_offer_pool_ids` 只有 3 条，那是**委托板当前挂出的可接任务**；玩家已接的任务在 `questComponent.quests` 里，以 `[宗门]` 开头。实际存档 `manual_06` 有 8 条已接（6 进行中 + 2 待提交），加上职位 `task_limit=10`，界面显示「已接 8/10 · 委托板 3 条 · 待提交 2」。只读 `current_offer_pool_ids` 会漏掉已接任务。
3. **委托板任务不能用来识别已接任务**：`tbsecttaskpool` 的 `quest_id` 是占位/剧情任务（如 1001、1002、1000016），与运行时任务日志里的 1300xxx 不是同一套 id；已接任务必须从任务日志按 `[宗门]` 名称关联 `tbquest`。
4. **当前贡献不等于累计贡献**：新存档可能出现 `sect_contribution_total=0` 而背包 50002 有 500；当前贡献必须取背包，累计取字段。
5. **负声望合法**：存档存在 `sect_reputes={"1":-100}`，界面按实际值展示，不做 0 截断。
6. **货架重复配置**：临州/砚州 800/1200/1600 档与 400 档物品完全相同；其余城镇 800 档与 400 档相同。界面逐档标注「与 X 档相同」，避免误以为还有新商品。
7. **600 档是唯一增量**：临州 600 档为玄霞露（2000 灵石），砚州 600 档为玄牝玉液（5000 灵石）；其余城镇没有 600 档。
8. **未开放城镇**：天雍、冥泉、杏花集、尽欢坞、古渡镇、朽牙镇、森罗鬼市有称号配置，但没有可刷新委托/货架；默认隐藏，勾选后可见。
9. **委托目标从任务目标文本解析**：地点取富文本里的 `地图.子地点`，目标取其余高亮词，数量取「采集/击败 N 个/只」；个别任务把目标写在前面、地点写在后面，解析时按是否含 `.` 判断，避免地点与目标互换。
10. **原型里的「本月预计 +7200」无法从配置或存档复现**：委托板 3 条任务的实际贡献合计为 3150。模块改为展示实测值，不再沿用该数字。
11. **同名功法不同阶**：如沧溟真诀 500/1500 贡献对应不同物品 id，不是重复配置；兑换列表按物品区分。
12. **任务奖励双来源**：`reward_contribution` 是贡献，`reward_drop_id` 里还含 35 点宗门声望；两者都展示，避免只看到贡献。
13. **`tbquest` 不是数组**：解包结果是 `{rows, overrides}`；build 侧统一从 `rows` 读取。
