# 宗门与声望模块

> 版本线：1.9（宗门/声望）
> 模块键：`sect`（宗门）、`reputation`（声望）
> 数据快照：`sect_meta.json`、`reputation_meta.json`

## 1. 目标与结论

把「宗门」和「城镇声望」两条独立循环做成两个只读页签，回答三个问题：

1. 我现在在宗门/城镇里处于什么位置，离下一档还差什么；
2. 本期还能拿多少贡献/声望/灵石，做完会不会跨档；
3. 手里的贡献/灵石能换什么，哪些兑换被职位、境界或声望卡住。

两条循环互不兑换：

- **宗门**：做宗门任务/灵材征收 → 贡献 + 宗门声望 → 贡献兑换藏经阁物品；宗门声望只用于职位晋升。
- **声望**：做城镇委托 → 城镇声望 + 灵石 → 城镇声望解锁货架档位；购买货架物品另花灵石。

已核对的关键数字：

- 每个可玩宗门 23 件兑换，单宗全清 **26240 贡献**（8 件灵果灵物 + 15 件功法招式）。
- 8 个开放城镇：临州、砚州、白獠部、归鹤镇、青岚洲、雨塘村、烈砂关、青麦村。
- 货架首档统一 400；临州/砚州另有 600 档特殊物品（玄霞露/玄牝玉液）；其余档位为重复配置。
- 委托每城每次刷新 9 条，单条 100–200 声望 + 150–900 灵石。

## 3. 页面结构

### 宗门（`sect`）

1. 五张卡：当前贡献 / 本期可领 / 累计贡献 / 宗门声望 / 灵石。
2. 职位晋升路径：外门弟子 → 内门弟子 → 真传弟子 → 长老 → 大长老；当前、已完成、下一职位分色。
3. 晋升条件：当前职位、宗门声望（进度条）、境界、晋升考核任务。
4. 本月收入：任务贡献、宗门声望、年俸、下次俸禄与刷新时间。
5. 本期任务：名称、类型、难度、职位门槛、贡献/声望、可领取/已完成。
6. 贡献兑换：全部/灵果灵物/功法招式筛选、搜索、只看可兑换、按价格/职位/名称排序；单品模拟兑换与重置。
7. 灵材征收：本期委托空态 + 可征收清单。

### 声望（`reputation`）

1. 五张卡：城镇声望 / 本期可获 / 已解锁货架 / 已见解锁 / 最高城镇。
2. 城镇总表：当前声望、称号、本月委托、完成后、跨档、下一档；默认按声望降序，可切城镇顺序。
3. 城镇 chip：快速切换；可显示未开放城镇（默认隐藏）。
4. 选中城镇详情：
   - 声望货架：每档门槛、解锁状态、价格、物品清单；重复档位标注「与 X 档相同」；本月可跨入的档位单独标记。
   - 本期委托：9 条明细，区分可接取/进行中，显示声望与灵石。
   - 称号档位：当前称号高亮。

## 5. 边界与数据坑

1. **宗门 6–10 是剧情势力**：凌霜宗、曜日阁、九劫雷狱、骸谷、世乐合欢有职位与任务，但没有藏经阁兑换 NPC；模块标记为不可加入，不伪造 23 件商品。
2. **当前贡献不等于累计贡献**：新存档可能出现 `sect_contribution_total=0` 而背包 50002 有 500；当前贡献必须取背包，累计取字段。
3. **负声望合法**：存档存在 `sect_reputes={"1":-100}`，界面按实际值展示，不做 0 截断。
4. **货架重复配置**：临州/砚州 800/1200/1600 档与 400 档物品完全相同；其余城镇 800 档与 400 档相同。界面逐档标注「与 X 档相同」，避免误以为还有新商品。
5. **600 档是唯一增量**：临州 600 档为玄霞露（2000 灵石），砚州 600 档为玄牝玉液（5000 灵石）；其余城镇没有 600 档。
6. **未开放城镇**：天雍、冥泉、杏花集、尽欢坞、古渡镇、朽牙镇、森罗鬼市有称号配置，但没有可刷新委托/货架；默认隐藏，勾选后可见。
7. **原型里的「本月预计 +7200」无法从配置或存档复现**：当前存档 3 条任务的实际贡献合计为 3150。模块改为展示「本期可领」实测值，不再沿用该数字。
8. **同名功法不同阶**：如沧溟真诀 500/1500 贡献对应不同物品 id，不是重复配置；兑换列表按物品区分。
9. **任务奖励双来源**：`reward_contribution` 是贡献，`reward_drop_id` 里还含 35 点宗门声望；两者都展示，避免只看到贡献。
10. **`tbquest` 不是数组**：解包结果是 `{rows, overrides}`；build 侧统一从 `rows` 读取。

## 6. 首版范围与后续
