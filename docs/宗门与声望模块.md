# 宗门与声望模块

> 版本线：1.9（宗门/声望）
> 模块键：`sect`（宗门）、`reputation`（声望）
> 数据快照：`sect_meta.json`、`reputation_meta.json`

## 1. 目标与结论

把「宗门」和「城镇声望」两条独立循环做成两个只读页签，回答三个问题：

1. 我现在在宗门/城镇里处于什么位置，离下一档还差什么；
2. 本期还有哪些顺路的宗门委托/城镇委托可接，收益多少，做完会不会跨档；
3. 手里的贡献/灵石能换什么，哪些兑换被职位、境界或声望卡住。

两条循环互不兑换：

- **宗门**：在宗门驻地「百机堂」打开「委托」面板接宗门委托 → 贡献 + 宗门声望 → 贡献兑换藏经阁物品；宗门声望只用于职位晋升。
- **声望**：做城镇委托 → 城镇声望 + 灵石 → 城镇声望解锁货架档位；购买货架物品另花灵石。

已核对的关键数字：

- 每个可玩宗门 23 件兑换，单宗全清 **26240 贡献**（8 件灵果灵物 + 15 件功法招式）。
- 8 个开放城镇：临州、砚州、白獠部、归鹤镇、青岚洲、雨塘村、烈砂关、青麦村。
- 货架首档统一 400；临州/砚州另有 600 档特殊物品（玄霞露/玄牝玉液）；其余档位为重复配置。
- 城镇委托每城每次刷新 9 条，单条 100–200 声望 + 150–900 灵石。
- **宗门委托**：可玩宗门（玄一门/焚天宗/镇岳宗/云芝山/砺剑盟）各有 65–66 条委托任务，
  每期随机挂 9 条，30 天刷新；单条 **150–900 贡献 + 100–300 宗门声望**（按难度 1–4）。
  职位门槛分两档：外门弟子/外门执事/内门弟子 或 真传弟子及以上；同时最多接 10 条，接后 90 天失效。

## 3. 页面结构

### 宗门（`sect`）

1. 顶部行动卡：待提交委托 / 进行中 / 可接委托 / 晋升；下方统计带显示当前贡献（含「再攒 X 可换某物」）、累计贡献、宗门声望、灵石、下期刷新。
2. 首屏主块「宗门委托」：
   - 一行操作指引：在「百机堂」场景顶部点「委托」按钮接取，30 天刷新 9 条，最多同时接 10 条，90 天不做会失效；
   - 「顺路」行：本期可接委托里同地点的合并成 chip（只有 ≥2 条时才显示）；
   - 待提交（金色高亮）→ 进行中（含进度与剩余天数）→ 本期可接（含类型、难度、职位门槛、贡献/声望奖励、地点与目标）；
   - 已提交委托折叠，下期刷新后移除。
3. 右栏晋升：只展示当前 → 下一职位的条件与进度，完整职位路径折叠；下方本期委托收益（可接/已接未交的贡献与声望、年俸）。
4. 底部贡献兑换：显示当前可兑换件数与「再攒 X 贡献可换「物品」」；支持全部/灵果灵物/功法招式筛选、搜索、只看可兑换、按价格/职位/名称排序、单品模拟兑换与重置。

### 声望（`reputation`）

1. 顶部行动卡：可接委托 / 可跨档城镇 / 下一档缺口 / 最高城镇；下方统计带显示总声望、开放城镇、已解锁货架、已见解锁。
2. 城镇 chip：可跨档的城镇优先，其次按可获声望与当前声望排序；可显示未开放城镇（默认隐藏）。
3. 选中城镇：顶部显示当前声望、完成后声望、可接与进行中数量。
4. 左栏先放「顺路清单」：按地点合并全部委托，聚合「本次需收集」的材料与总数；下方再列本期委托明细，区分可接取/进行中，显示目标描述、地点、目标物/怪物/NPC、数量与品质。
5. 右栏放声望货架与称号档位：每档门槛、解锁状态、价格、物品清单；重复档位标注「与 X 档相同」；称号档位折叠，当前称号高亮。
6. 底部城镇总表：当前声望、称号、本月委托、完成后、跨档、下一档缺口；本月可跨档的城镇高亮，点击行切换城镇。

## 5. 边界与数据坑

1. **宗门 6–10 是剧情势力**：凌霜宗、曜日阁、九劫雷狱、骸谷、世乐合欢有职位与委托势力配置，但委托池为空、没有藏经阁兑换 NPC；模块标记为不可加入，不再输出「未配置藏经阁」告警，只在可加入列表里说明。
2. **旧执事堂已成废弃配置**：`tbsecttaskpool` / `tbsectpurchaseorder` 对应的执事堂交互动作 604 没有被任何 NPC 交互规则或场景 UI 引用；任务池里 type 2–4 的 `quest_id` 全是 0，type 1 指向 `1001 初到河望镇`、`1002 客栈歇脚`、`1000016 委托·访友` 等无关任务。存档里 `sectComponent.task_component.task_records` 也为空。模块已移除这块 UI，不再使用「外务委托 / 宗门差遣 / 宗门要务 / 宗门重任」这些游戏里不存在的叫法。
3. **现行宗门委托走 commission 系统**：`tbcommissionforce.force_type=2` + `tbcommissiontaskpool`，任务内容是 `tbquest` 里的 `[宗门]` 任务（1200xxx / 1300xxx）。入口不是 NPC 对话，而是宗门「百机堂」场景顶部 `tbspaceinteractui` 的 `interactActionId=10901`「委托」按钮；`tbcommissionforcetaskrefresh.entry_npc_id` 只是该场景的执事长老。
4. **职位门槛是白名单，不是下限**：`tbcommissiontaskpool.sect_position_id` 列出的职位才能接。可玩宗门每条委托只开放给「外门弟子/外门执事/内门弟子」或「真传弟子及以上」其中一档，所以高职位玩家反而接不了外门档委托；界面按白名单显示「岗位不符」。
5. **委托常量在 tbconstants 主表**：`COMMISSION_TASK_REFRESH_DAYS=30`、`COMMISSION_TASK_MAX_ACCEPTED_PER_FORCE=10`、`COMMISSION_TASK_COMPLETION_DAYS=90`。`meta_update` 对分片表只保留首个同名资源，build 取不到时回退到以上实测值。
6. **当前贡献不等于累计贡献**：新存档可能出现 `sect_contribution_total=0` 而背包 50002 有 500；当前贡献必须取背包，累计取字段。
7. **负声望合法**：存档存在 `sect_reputes={"1":-100}`，界面按实际值展示，不做 0 截断。
8. **货架重复配置**：临州/砚州 800/1200/1600 档与 400 档物品完全相同；其余城镇 800 档与 400 档相同。界面逐档标注「与 X 档相同」，避免误以为还有新商品。
9. **600 档是唯一增量**：临州 600 档为玄霞露（2000 灵石），砚州 600 档为玄牝玉液（5000 灵石）；其余城镇没有 600 档。
10. **未开放城镇**：天雍、冥泉、杏花集、尽欢坞、古渡镇、朽牙镇、森罗鬼市有称号配置，但没有可刷新委托/货架；默认隐藏，勾选后可见。
11. **委托目标从任务目标文本解析**：地点取富文本里的 `地图.子地点`，目标取其余高亮词，数量取「采集/击败 N 个/只」；个别任务把目标写在前面、地点写在后面，解析时按是否含 `.` 判断，避免地点与目标互换。炼器/炼丹委托没有地点高亮，归为「任意地点」。
12. **原型里的「本月预计 +7200」无法从配置或存档复现**：旧模块把委托板 3 条任务的贡献合计写成 3150；现在改为展示存档里的本期委托实测值。
13. **同名功法不同阶**：如沧溟真诀 500/1500 贡献对应不同物品 id，不是重复配置；兑换列表按物品区分。
14. **任务奖励双来源**：旧委托板的 `reward_contribution` 与 `reward_drop_id` 已废弃；现行委托的贡献/声望都从 `reward_drop_id` 的掉落里取（50002 宗门贡献 + 各宗声望物品）。
15. **`tbquest` 不是数组**：解包结果是 `{rows, overrides}`；build 侧统一从 `rows` 读取。

## 6. 首版范围与后续

首版已覆盖：职位与晋升、贡献兑换（含模拟）、宗门委托（本期可接/进行中/待提交/顺路）、城镇总表、货架档位、委托明细、称号档位。

二期候选（未做）：

- 兑换后背包数量与「已拥有」校验；
- 委托历史与月度收益曲线；
- 按角色保存模拟兑换状态。
