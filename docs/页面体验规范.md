# 页面体验规范

适用于浮窗（WebView2 overlay）与网页预览。改页面前先按本文件审计，改完按第八节验收。
上位原则见《并行开发约定.md》第六章「产品设计原则」。
字号、颜色、圆角、间距的具体取值见 [视觉规范.md](视觉规范.md)。

## 一、基准尺寸

- 基准视口是浮窗 **960×632**（overlay size level 2），不是桌面全屏。判断「首屏够不够」必须在这个尺寸实测，不能看宽屏截图。
- 用 `getBoundingClientRect()` 取元素 top 判断是否在首屏，不靠目测。「搜索框在 top 1133」比「感觉有点靠下」有说服力。

## 二、首屏只回答一件事

- 每个模块先确定「用户此刻要做的一件事」，最高频入口必须滚动 **0 次**可见。
- 反例：炼丹搜索框曾被埋在 1133px 处。
- 统计卡对「即将执行的动作」无帮助时压缩成一行小字，把首屏让给操作入口。

## 三、搜索型与浏览型分开处理

- **搜索型**（炼丹、NPC 天赋、物品、NPC 物品）：搜索框与结果入口必须在首屏。
- **浏览型**（境界修为、红尘、奇遇、宗门、炼器）：主内容从 y≈248 起已可见，搜索靠后是合理取舍，不要机械上移。
- 判断依据是「用户打开这页第一件事是找东西还是看结论」，不要套统一模板。

## 四、触发点与结果同屏

- 点列表项、搜索命中、跳转后，详情与地图不能滚出视口；验收标准是全程回滚次数为 0。
- 主从结构（详情 + 列表）**先量可用高度再决定是否独立滚动**。给内容栏设 `max-height:calc(100vh - Npx)` 很容易把列表压成一条缝（实测右栏 482px、详情 279px，只剩 193px 给筛选+列表）。
- 判定：扣掉固定头部后剩余高度 < 400px 就不要做独立滚动，让页面自然滚动、详情留在文档流（`position:relative`）。
- `sticky` 只适合高度很小的信息条；258px 的面板贴顶会让下方内容从它下面穿过。

## 五、信息密度

- 高级筛选（五行/阶数/药效等）默认折叠，不占首屏；基础「显示对象」常驻。
- 长规则说明、配置解释收进 `<details>`，不要平铺占掉首屏。
- 图例必须紧贴它解释的对象（地图图例放地图旁），不能沉到页面最底部。
- 卡片只保留做决策用的标记，同一结论不要在多处重复。

## 六、文案

- 写完整短语再拼接：「墨巧巧·留影之一」，不要「墨巧巧·之一」。
- 状态用玩家语言：「已寿终 / 已退隐 / 尚未登场」，不要统一写成「隐退」。
- 层数、档位等要写明确数字，禁止「第20多层」这类模糊表述。

## 七、数据正确性（硬规则）

- 面向玩家的文本不得出现内部编号；无对应名称时降级为「未识别物品 / 未识别属性 / 未识别天赋 / 未记录结局」。
- 缺数据就留白，不要补默认值假装有数据（例如赠礼剩余次数没有数据源就不显示）。
- 品质名称与游戏 `ITEM_QUALITY_DICT` 同源；越界时和游戏一样回退数字，不编造名称。
- 凡「按名字搜索」的入口，都要配一条「按功效/用途」的路径；功效词命中数从当前数据实时统计，0 命中自动隐藏。
- 按功效搜索时，真对象排在属性/附属点之前（炼丹：丹方优先于丹方属性点）。

## 八、验收闭环

1. 在 960×632 下量首屏：目标入口 top 是否 < 632。
2. 走一次完整动作链：搜索 → 点击 → 确认结果，回滚次数必须为 0。
3. 查数据：是否出现内部编号、是否有编造名称、缺数据是否留白而非填充。
4. 查降级：无数据、未识别状态是否有明确文案。

## 九、各模块用户痛点（产品输入）

每个模块要解决的第一问题，功能优化与工坊描述都以此为准：

- 奇遇/支线/红尘：①任务触发条件 ②选项条件一览 ③奖励一览
- NPC 物品：①是否可偷/可索要/可赠礼 ②偷窃成功率与是否致命、索要成功率、赠礼剩余次数
- NPC 天赋：想找的天赋在哪个 NPC 身上、位置在哪
- 人物图鉴：NPC 善恶值、境界、位置、关系一览
- 境界修为：①所需突破材料的稀有妖兽是否刷新 ②各突破材料怎么获取
- 炼丹：炼丹地图、丹方筛查（所需丹方在什么位置、怎么传送）
- 炼器：还剩多少次保底
- 赌石：①卖给哪个收购商更值 ②石头价值参考 ③已刮参考
- 拍卖会：①直接显示未揭示物品 ②参考出价
- 宗门：①是否有顺路可做的宗门任务 ②贡献是否够兑换当月物品
- 声望：①是否有顺路可做的声望任务 ②是否还有未解锁的商店物品
- 仙居楼互动：①每位仙友各部位还差多少阶段未互动 ②十八摸成就进度
- 留影石：①本月可做哪些留影 ②留影进度一览
- 心法与功法：①心法/功法/共鸣一览 ②配置体检

写工坊功能描述时，以下为最常用、最有价值项，需加粗突出：
仙居楼互动①、留影石①、炼丹①、NPC 天赋①，以及奇遇/支线/红尘三项、境界修为②。
