# 视觉规范

浮窗 960×632 的视觉基线。改页面前先按本文件取值，不要临时拍一个数字。
交互与信息层级的要求见《页面体验规范.md》，本文只管「长什么样」。

## 一、颜色只有一套

全部来自 `app/output.py` 的 `:root` 令牌，模块 CSS 不写死色值（新增语义色先加令牌再引用）。

| 用途 | 令牌 |
|---|---|
| 页面底色 / 卡片 / 下沉块 | `--bg` / `--surface` / `--surface-sunken` |
| 描边（轻→重） | `--border` / `--border-subtle` / `--border-strong` |
| 文字（亮→暗） | `--text` / `--text-soft` / `--text-body` / `--text-dim` / `--text-muted` / `--text-faint` |
| 主色（可执行、进度） | `--accent` / `--accent-bg` / `--accent-fg` |
| 语义 | `--ok*` 成功、`--gold*` 珍稀/提示、`--danger*` 危险、`--info*` 中性信息 |
| 强弱档 | `--gold-strong/soft/warm/line`、`--ok-strong/solid/pale`、`--danger-strong/line`、`--info-strong/line`、`--ink-strong/ink` |

同一结论只用一种颜色表达。品质色走 `--qN` 档位类，不手写。

## 二、字号四档，别再加第五档

| 档 | 用途 |
|---|---|
| 20px | 页面主数字（统计卡数值）、卡片标题上限 |
| 16px | 区块标题、角色名 |
| 13px | 正文与可点条目 |
| 12px | 次要说明、字段名 |
| 11px | 徽标、脚注、来源行 |

**下限 11px。** 10px 中文在 96dpi 下发糊，历史遗留的已在 2026-11-27 统一抬高。
数字一律加 `font-variant-numeric:tabular-nums`，避免跳动。

## 三、圆角四档

`6px` 徽标/小标签 · `8px` 输入框与按钮 · `12px` 卡片与面板 · `20px` 胶囊/分段控件。
圆形头像与进度环用 `50%`。不要出现 3/4/5/7/9/10/11px 这类中间值。

## 四、间距按 4 的倍数

`4 / 8 / 12 / 16 / 24`。卡片内边距 `11px 15px` 或 `12px 14px`，卡片间距 `10~12px`，
区块间距 `16~22px`。同一屏里相邻两个区块的间距必须一致。

## 五、组件约定

- **统计卡**：`.cards` 是等宽自适应网格，几张卡都会铺满一行；数值 20px/600，标题 12px `--text-muted`。
- **徽标**：`.badge` 11px，底色 `--surface-raised`；带状态语义时用对应语义色的 `-bg` + 文字色。
- **折叠块**：一律 `<details>`，摘要行 12px，箭头用 `›` 旋转 90°，默认收起（除「高级筛选」有值时自动展开并显示 `（N）`）。
- **筛选**：基础维度常驻一行；类型/区域/位置这类收进「更多筛选」，别让首屏被下拉框占满。
- **页签**：等宽网格，两行内放下，选中态 `--accent-bg` + `--accent` 描边。
- **来源行**：单行省略，完整信息进 `title`，存档名不显示机器 GUID。

## 六、交互反馈

- 可点行、卡片、折叠摘要都要有 hover：底色或描边变化即可，不要用位移和缩放。
- 长表格 `th` 吸顶（`position:sticky;top:0`），吸顶底色必须是 `--bg`，否则行会从下面透出来。
- 过渡统一 `.12s`，只过渡 `background / color / border-color`。

## 七、深色环境

- `:root{color-scheme:dark}` 必须保留，否则原生下拉弹层和滚动条会变白。
- 滚动条统一 10px 深色滑块，`::selection` 用 `--accent-bg` 系。
- 不用纯黑 `#000` 与纯白 `#fff`；最暗用 `--bg`，最亮用 `--text`。

## 八、改完怎么验

`tmp/measure/` 下的脚本（不入库）：
- `audit.py --dismiss` 逐页量首屏与内部编号；
- 单页截图用 `chrome --headless=new --window-size=996,737`（视口正好 960×632）。
命中「首输入 > 632」时先判断该模块是搜索型还是浏览型，别机械上移。
