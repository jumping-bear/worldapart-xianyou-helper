# 打包环境备忘

记录打 EXE 用哪个环境、踩过什么坑。改打包流程前先读这份。

## 好的环境（当前唯一验证可用的）

- **解释器**：`py -3.12`（`C:\Users\Hason Shaw\AppData\Local\Programs\Python\Python312`）
- 关键包版本（2026-11-27 验证）：PyInstaller 6.22.3、pythonnet 3.2.1、clr_loader 0.3.1、UnityPy 1.25.4、pywebview 6.2.1
- **Pillow 必须保留**：头像 webp 解码依赖它（`app/modules/memoria/avatars.py`），不能加入 excludes
- 其他解释器不可用：3.8 只有 PyInstaller 4.10（过旧），3.13 没装 PyInstaller

## 已踩过的坑：环境混入开发库导致 EXE 翻三倍

2026-11-27 v2.4.0 重打包时，3.12 环境里被手工装入了 matplotlib 3.11.2 和
PySide6 6.12.0（没有任何包依赖它们，属于开发期临时安装）。PyInstaller 的
matplotlib hook 会连带收集 Qt 后端，结果：

- EXE 27.7MB → 79.1MB（PySide6 压缩后占 36.2MB、matplotlib 占 6.6MB）
- 玩家每次工坊更新要多下载约 51MB

**防护**：`TouchProgress.spec` 的 `excludes` 已显式排除
`matplotlib` / `PySide6` / `shiboken6`，构建环境再脏也不受影响。
程序不 import 这三者，排除无副作用。

## 验收标准

- 打包后 `仙友助手.exe` 应在 **28MB 左右**；明显超过（如 >35MB）先查环境混入了什么
- 快速核对：EXE 内不应出现 `PySide6`、`matplotlib` 字样
  （可用 `tools/inspect_pyinstaller.py` 或直接按字节搜索）
- 冻结包跑一次 `仙友助手.exe --once --no-browser`，无「功能模块加载失败」

## 打包命令

日常验证（不走进正式发布流程）：

```
py -3.12 -m tools.packaging --check
py -3.12 -m PyInstaller TouchProgress.spec --noconfirm --distpath tmp/dist --workpath tmp/build
```

正式发布用 `tools/release.py`（含 version.json 哈希刷新与私有机密清理），
发布前预检：`python tools/release.py --check`。
