[h2]FAQ[/h2]
[list]
[*][b]Where is the workshop folder?[/b] `Steam\steamapps\workshop\content\4209920\3839624741`, or right-click the game in Steam, Manage > Browse local files. Look for 一键安装.bat inside.
[*][b]No BepInEx\decrypted folder?[/b] The plugin did not load. Fully close the game, run 「一键安装.bat」 again and check that every self-check shows ✓.
[*][b]Does it conflict with other BepInEx plugins?[/b] The installer only adds this tool's plugin and leaves the BepInEx core untouched.
[*][b]Which save does it read?[/b] The newest save of each character by default. To inspect another one, save it again in-game; or pin a save in 「功能设置.bat」.
[*][b]No data in the tool?[/b] The save copy is exported 15-20 seconds after the game starts; click "Sync now" in the top bar to refresh at once.
[*][b]F3 does nothing / updating from an old version?[/b] On v2.2.0 or older, close the game and run 「一键安装.bat」 one last time; v2.3.0 and later update automatically. Close anything else holding F3.
[*][b]Steam download failed / no response after update?[/b] Fully exit the game and the helper, then verify the game files. If it still fails, unsubscribe, restart Steam and subscribe again. The plugin verifies the workshop EXE and keeps the old version if the download is incomplete.
[/list]
